# Useful Knowledge

A repository for storing useful knowledge for both **Agents** and **People**.

## Purpose

This repo is a lightweight knowledge base where:
- Agents can find concise, task-ready guidance.
- People can find practical references and shared team knowledge.

## Structure

- `knowledge/agents/` — instructions, patterns, and operational notes tailored for automated agents.
- `knowledge/people/` — human-readable guides, conventions, and reference material.

## Contributing

1. Add or update content in the correct audience folder (`agents` or `people`).
2. Keep entries clear, scoped, and easy to scan.
3. Prefer small, focused updates so knowledge stays maintainable.
